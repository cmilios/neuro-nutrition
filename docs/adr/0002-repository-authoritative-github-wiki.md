# Keep GitHub Wiki content authoritative in the repository

**Audience:** maintainers changing user documentation or Wiki publication.

**Purpose:** record why repository-authored Wiki source is authoritative and
direct Wiki edits are unsupported.

GitHub Wiki content is authored under `docs/wiki/` in the main repository and published automatically to the repository's GitHub Wiki. This keeps user documentation reviewable, testable, and versioned with application changes; the Wiki is a generated publication target, so direct Wiki edits are intentionally unsupported because a later publication would overwrite them.
