# Start Over

_For signed-in NeuroNutrition users considering removal of the Current Weekly
Plan. Read what remains before confirming this action._

[Return to the user-guide Home](https://github.com/cmilios/neuro-nutrition/wiki) ·
[Use your Weekly Plan](https://github.com/cmilios/neuro-nutrition/wiki/Using-Your-Weekly-Plan)

## What Start Over does

Start Over removes the Current Weekly Plan by deactivating it. After it
succeeds, that plan is no longer the active plan shown in the app, and you can
create a fresh Weekly Plan from the Health Profile.

Start Over is not permanent account-data deletion.

## What remains saved

Start Over preserves:

- the Health Profile;
- milestones;
- AI Usage Records; and
- inactive Weekly Plan history.

Ingredient progress belongs to its Weekly Plan. It is no longer shown as
current progress after that plan is deactivated, although the inactive plan
history remains saved.

## Restoration limitation

You cannot restore the removed plan in the app. Creating another Weekly Plan
does not reactivate the former one; it creates a new Current Weekly Plan.

If you only want a different meal, use a Meal Reroll. If you want a successor
shaped by the week's Meal Review, create a Next Weekly Plan. If updated
plan-relevant Health Profile information should shape the plan, use Health
Profile Plan Replacement. None of those actions is the same as Start Over.

## Confirm Start Over

1. Open the account menu and choose **Start Over**.
2. Review the warning, then select **Start Over** to open the confirmation.
3. Confirm only when you are ready to remove the Current Weekly Plan.
4. Wait while **Starting over…** is shown.

The control is unavailable when there is no Current Weekly Plan or while plan
changes are still being checked.

If the app reports a failure, the Current Weekly Plan remains until removal is
confirmed. Use the app's offered **Retry** control once; it safely continues or
restarts the recorded action. If the plan is checking, read-only, or the outcome
is unknown, do not submit Start Over from another tab, browser, or device. Wait
for reconciliation before taking another action.
